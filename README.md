
🏘️ Property Value Estimator

A Machine Learning web application built using Python, Streamlit, and scikit-learn that predicts residential property prices based on property features.

---

🚀 Features

- 📐 Predicts house prices using Linear Regression
- 🎈 Interactive Streamlit web interface
- 📊 Data visualizations & analytics
- 🌙 Modern dark-themed UI
- 🤖 Machine Learning powered predictions
- 📁 Dataset preview and model metrics

---

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- scikit-learn
- Matplotlib
- Seaborn

▶️ How to Run the Project

1️⃣ Clone Repository

bash
git clone https://github.com/yashika26-bot/property-value-estimator.git


2️⃣ Open Project Folder

bash
cd property-value-estimator


3️⃣ Install Dependencies

bash
pip install -r requirements.txt


4️⃣ Run Streamlit App

bash
streamlit run app.py
